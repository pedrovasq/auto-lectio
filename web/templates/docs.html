Documentación

Cómo funciona AutoLectio y cómo preparar tus plantillas.

Esta guía resume el flujo del sistema, la estructura de placeholders y los criterios básicos para construir plantillas reutilizables en PowerPoint.

Resumen del flujo

  1. El sistema obtiene las lecturas del día desde la fuente configurada.
  2. El contenido HTML se transforma a una estructura más limpia y consistente.
  3. Las lecturas se convierten en placeholders y bloques de texto listos para renderizar.
  4. La plantilla PPTX se llena con esos valores y se expanden las lecturas largas.

Qué contiene una plantilla

Una plantilla usa placeholders de texto como {FIRST_READING_TXT} o {GOSPEL_REF}. AutoLectio busca esos tokens en las diapositivas y los reemplaza con el contenido correspondiente.

Para lecturas largas, la plantilla debe incluir una diapositiva semilla para cada bloque principal. A partir de esa semilla, el renderer crea las diapositivas adicionales necesarias.

Placeholders principales

  • {LITURGICAL_DAY} para el título o contexto litúrgico.
  • {FIRST_READING_REF} y {FIRST_READING_TXT}.
  • {PSALM_REF} y {PSALM_TXT}.
  • {SECOND_READING_REF} y {SECOND_READING_TXT}.
  • {ACCLAMATION_RES} y {ACCLAMATION_VERSE}.
  • {GOSPEL_REF} y {GOSPEL_TXT}.

Cómo crear una plantilla

  • Diseña cada diapositiva en PowerPoint con el estilo visual final.
  • Inserta los placeholders como texto editable, preferiblemente en una sola corrida de texto.
  • Reserva una diapositiva semilla para cada lectura que pueda crecer a varias diapositivas.
  • Prueba la plantilla con un día que tenga lecturas largas para validar el comportamiento real.

Lecturas largas y técnica de waterfall

Cuando una lectura no cabe cómodamente en una sola diapositiva, AutoLectio divide el contenido en fragmentos balanceados. Luego toma una diapositiva semilla y la duplica tantas veces como sea necesario, reemplazando solo el cuerpo del texto.

Esto permite mantener el mismo diseño sin reconstruir manualmente cada continuación.

Cantos y partes fijas

El modo avanzado también admite contenido para cantos y algunas partes fijas de la Misa. Ese contenido se integra mediante placeholders dedicados y puede expandirse en varias diapositivas si hace falta.
